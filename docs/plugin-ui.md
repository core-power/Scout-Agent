# 插件管理界面使用指南

## 概述

Scout Agent 现在提供了一个直观的 Web 界面来管理所有插件，无需编写命令行即可轻松启用、禁用、重新加载和配置插件。

## 访问插件管理界面

启动 Scout Agent Web 服务后，可以通过以下方式访问：

1. **直接访问**: `http://localhost:8848/plugins`
2. **从主页导航**: 点击顶部导航栏的插件图标（拼图图标）

## 界面功能

### 统计面板
显示三个关键指标：
- **总插件数**: 系统中已安装的所有插件
- **已启用**: 当前处于启用状态的插件数量
- **已禁用**: 当前处于禁用状态的插件数量

### 插件卡片
每个插件显示为一个卡片，包含：

#### 基本信息
- 插件名称
- 版本号
- 作者信息
- 插件描述
- 优先级（数字越小优先级越高）

#### 状态指示器
- 绿色标签表示"已启用"
- 灰色标签表示"已禁用"

#### 操作按钮
1. **启用/禁用开关**: 点击切换插件状态
2. **重新加载按钮** (🔄): 重新加载单个插件（用于应用代码更改）
3. **配置按钮** (⚙️): 查看和编辑插件配置

### 全局操作
- **重新加载全部**: 页面顶部按钮，用于重新加载所有插件

## 使用场景

### 场景 1: 启用/禁用插件
1. 找到目标插件卡片
2. 点击右侧的开关控件
3. 系统会显示成功提示并自动刷新统计

### 场景 2: 修改插件配置
1. 点击插件卡片上的配置按钮 (⚙️)
2. 在弹出的模态框中查看当前配置（JSON 格式）
3. 编辑配置内容
4. 点击"保存配置"按钮
5. 配置会立即生效

### 场景 3: 开发调试
1. 修改插件代码后
2. 点击插件卡片上的重新加载按钮 (🔄)
3. 或者点击顶部的"重新加载全部"按钮
4. 插件会重新加载并应用最新代码

## API 接口

插件管理界面通过以下 RESTful API 与后端通信：

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/plugins/` | GET | 获取所有插件列表 |
| `/api/plugins/{name}` | GET | 获取单个插件信息 |
| `/api/plugins/{name}/toggle` | POST | 切换插件启用状态 |
| `/api/plugins/{name}/reload` | POST | 重新加载单个插件 |
| `/api/plugins/reload-all` | POST | 重新加载所有插件 |
| `/api/plugins/{name}/config` | GET | 获取插件配置 |
| `/api/plugins/{name}/config` | POST | 更新插件配置 |

## 注意事项

1. **配置格式**: 插件配置必须是有效的 JSON 格式，否则保存会失败
2. **重新加载**: 重新加载插件会重置插件状态，可能影响正在进行的对话
3. **优先级**: 优先级数字越小，插件在事件链中执行越靠前
4. **持久化**: 启用/禁用状态和配置更改会自动保存到文件

## 故障排除

### 界面无法加载
- 检查 Web 服务是否启动: `scout --web`
- 确认端口 8848 未被占用
- 查看浏览器控制台是否有错误信息

### 插件操作失败
- 检查插件名称是否正确
- 查看服务器日志获取详细错误信息
- 确认插件文件没有语法错误

### 配置保存失败
- 验证 JSON 格式是否正确（可使用在线 JSON 验证工具）
- 检查文件权限是否允许写入
- 查看服务器日志获取详细错误信息

## 示例：创建自定义插件

1. 创建插件目录：`~/.scout/plugins/my_plugin/`
2. 创建 `__init__.py` 文件
3. 在插件管理界面点击"重新加载全部"
4. 新插件会出现在列表中
5. 通过界面启用插件并配置参数

详细开发指南请参考 [插件开发文档](plugins.md)
