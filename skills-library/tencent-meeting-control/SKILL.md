# 腾讯会议操控（2026-09-11 v2 重写：网页版优先 + 客户端踩坑全录）

## 路线选择（重要）
| 场景 | 首选路线 | 理由 |
|---|---|---|
| 预定/预约会议 | **网页版 meeting.tencent.com**（browser 工具） | 标准 HTML 控件，日期时间直接 fill，比客户端稳定 10 倍 |
| 加入会议/查看会议列表 | 客户端（desktop 工具） | 进程常驻，UIA 树可用 |
| 客户端不可用时 | 一律网页版 | 注册表安装路径可能是幽灵残留（卸载残留），以进程/窗口实际存在为准 |

## 首选路线：网页版预约
```
1. browser 打开 meeting.tencent.com（需已登录；未登录提示用户扫码）
2. 「预定会议」→ 表单：主题 fill、日期 fill、开始时间/时长 fill/select
3. 提交 → 核对结果页的日期时间与要求一致
```
网页表单是标准控件，browser 工具的 fill/click 走 playwright，无像素定位问题。

## 备用路线：客户端预约（2026-09-10 实测踩坑全录）
腾讯会议是 Qt 应用：**主窗口 UIA 树可用**（ControlType.Window | name='腾讯会议'），
但日期控件是分段编辑器，整串输入会被逐字符解析成乱值（实测 "2026/9/11" 变 2/2、4/2）。

```
1. launch/find_window process=WeMeetApp（托盘化自动恢复）
2. activate → screenshot 观察主界面
3. 打开"预定会议"：find='预定' 或 click_control
4. ★ 日期：desktop action=set_date date=2026-09-11（专用原语，年→月→日逐段键入）
   —— 手动输入规则：click 年段 → 键入 4 位数字（自动跳段）→ 月 2 位 → 日 2 位
   —— 严禁整串输入/粘贴 "2026/9/11"
5. 时间：QTimeEdit 同为分段控件，同 set_date 逻辑逐段键入（15:00 → "15" "00"）
6. 时长：下拉框 click 后 listitem 按名选（"1 小时"）
7. 提交前 ★必须截图核对：日期/时间/时长与用户要求完全一致才点"预定"
8. 提交后核对：进入"全部会议"列表确认会议已建在正确日期——
   发现错误日期的会议（误建）立即删除
```

## 客户端已知坑
- 安装路径注册表残留：HKLM 指向 D:\tencent_meeting\WeMeet 但目录不存在（卸载残留）——
  判断是否可用看**进程/窗口**（tasklist / list_windows），别信注册表
- 点击日历图标可能无反应（自绘弹层）——直接用键盘分段输入日期
- 误点"预定"可能建出错误日期的会议——提交前截图核对 + 提交后列表核对（双保险）

## 验证标准
预约成功的唯一标准：会议列表中出现目标日期+时间的会议（截图为证），
仅"预定"按钮点击成功不算数。
