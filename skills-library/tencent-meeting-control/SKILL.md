# 腾讯会议 预定会议 + 微信发链接（配方，2026-09-05）

> 通用方法论见 `windows-gui-control`；微信发送段复用 `wechat-desktop-control`。

## 心法（先读这个）

- 腾讯会议**没有**可用的本地 API/RPC/hook：预定会议、拿链接只能走 GUI（desktop 工具）。
- **登录态是唯一硬前置**：未登录账号前，GUI 里不存在任何「预定/复制邀请」入口。
  若启动后看不到已登录账号（头像/名字），**立即停下来向用户说明需要扫码/登录**，
  并请用户完成登录后回复「继续」——不要截图空转 100 步去“找登录成功的办法”。
- 界面全自绘：**先探测后锁定**。第一次操作某版本时，用
  `read_controls` / `screenshot`+vision **一次性发现**关键控件位置，换算成
  **rel 坐标**记录到本技能（下方预留），之后所有预定操作打包成 `macro`，
  绝不让模型每步重新“截图→看→猜”。
- 坐标防错：对部分暴露 UIA 控件的按钮，点前 `probe rel_x=.. rel_y=..`
  确认命中控件名；`click` 会自动吸附到控件中心（回复带 `吸附→Button`），
  点完没吸附行且界面无变化 = 点偏，probe 修正后再点。
- 成功标准：**目标微信会话中出现会议邀请卡片/链接文本**（截图验证），
  而不是“点了复制按钮”。

## 第一步：能力缺口预检（防空转，先做）

1. `launch target=WeMeeting`（或实际进程名 `WemeetApp`）→ `activate`。
2. `screenshot window_only=true` → vision 判定：主界面是否已登录（有账号头像/名字/“预定会议”入口）。
   - 未登录/弹登录窗/要扫码 → **停**。向用户如实汇报：需要人工扫码登录，完成后再继续。
   - 已登录 → 继续。

## 第二步：预定会议（GUI 骨架；坐标按你的版本回填后固化成 macro）

界面版本差异大，以下只给步骤骨架（不做不实坐标承诺）：

1. 点“预定会议”（通常在主界面右侧大按钮）。
2. 填写：主题（可选）、**开始时间=明天 14:00、时长 60 分钟**、成员类型（内部/外部）。
3. 点“预定/创建”。到“预定成功”页。
4. 复制邀请信息（“复制邀请”按钮或全选邀请文本 ^a → ^c）：得到会议号 + 链接 + 密码。
5. 剪贴板验证（`clip_read` 或粘贴到记事本再读）确认真拿到「会议号+链接」，否则不算成功。

坐标发现方法：`read_controls` 读控件名/auto_id 优先；读不到就
`screenshot`+vision 读文字判位置 → 换算 rel → **写回本技能下方坐标表** → 用 macro 固化：

```json
// 预定会议宏（坐标替换为你的实测值；最后一步把邀请文本放进剪贴板后结束）
{"steps":[
  {"action":"click","process":"WemeetApp","rel_x":<x>,"rel_y":<y>},      // 预定会议按钮
  {"action":"click","process":"WemeetApp","rel_x":<x>,"rel_y":<y>},      // 开始时间(明天14:00)
  {"action":"click","process":"WemeetApp","rel_x":<x>,"rel_y":<y>},      // 时长 60 分钟
  {"action":"click","process":"WemeetApp","rel_x":<x>,"rel_y":<y>},      // 预定/创建
  {"action":"sleep","seconds":2.0},
  {"action":"click","process":"WemeetApp","rel_x":<x>,"rel_y":<y>}       // 复制邀请
],"process":"WemeetApp"}
```

本机实测坐标（回填后本技能升级为“实测版”）：

| 控件 | rel_x | rel_y | 版本 |
|---|---|---|---|
| 预定会议按钮 | | | |

## 第三步：发给微信联系人（复用 wechat-desktop-control 场景 C）

1. 确认剪贴板里有完整邀请文本（会议号+链接+密码）。
2. 微信侧：切到目标会话（场景 B，先截图确认标题=联系人，**不可省**）。
3. macro 打包发送：点击输入框 rel(0.5,0.93) → `type_text paste=true` 或 `press_key ^v` 粘贴邀请 → 点发送按钮 rel(0.46,0.94)。
4. `verify_screenshot=true` 截图确认气泡出现。

## 防坑

| 坑 | 对策 |
|---|---|
| 未登录就找“预定会议” | 登录态预检，卡住即向用户要扫码 |
| 界面自绘无控件名 | read_controls → vision 读文字 → rel 坐标，一次发现即固化 macro |
| 复制了但没拿到链接 | clip_read 验证；失败重试复制 |
| probe 报「点不在窗口矩形内」 | 坐标是窗口截图内坐标而非屏幕坐标——改 rel_x/rel_y 表达再点；窗口内会附 rel≈ 值 |
| 会议默认今天/错误时间 | 预定表单逐项截图核对时间=明天 14:00、时长 60 分钟 |
| 发到错误会话 | 发送前截图确认右侧标题=目标联系人 |
