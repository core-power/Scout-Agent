如何实现"文件变化 → Agent 自动处理"

  1. 在左侧添加要监听的目录（支持递归）。
  2. 点击「启动监听」，agent 会持续感知该目录的文件新增/修改/删除。
  3. 前往 自动化中心 创建一个 event 触发器，事件名填 fs.event。
  4. 在任务模板中使用占位符引用文件信息，例如：
任务模板:
  检测到文件变化:{{event.relative}} ({{event.event_type}})
  请根据需求处理该文件。

可选过滤器（event_filters）:
  {"event_type": "created"}   只监听新增
  {"relative": "*.pdf"}       只监听 PDF 文件
事件类型：created 新增 · modified 修改 · deleted 删除。每个事件含 path / relative / size / mtime 字段。
